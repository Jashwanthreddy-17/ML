    How it works

    1. Data: IPL ball-by-ball deliveries ( player-innings for training).
    2. Target: innings_runs — runs credited to the batter in one innings (extras excluded, zeros kept).
    3. Features: career average, strike rate, recent form (last 5 / last 3 innings), consistency, days since last match — all computed from innings before the one being predicted, plus pre-innings context (innings, venue, teams).
    4. Models: Ridge (L2 shrinks all coefficients) and Lasso (L1 also zeroes out weak features) vs a mean baseline.
    5. Validation: chronological split — the models never see future matches during training.
